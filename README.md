# CareerHub — жұмыс орындарын іздеу веб-қосымшасы

## Маңызды
Бұл нұсқа курстық жұмыста бұрын жасалған SQLite деректер базасын қолданады.
`main.py` ішінде `CREATE TABLE`, `DROP TABLE` немесе деректер базасын қайта құру коды жоқ.
Бағдарлама `docs/vacancies.db` файлын ашып, бар `Users`, `Companies`, `Vacancies`,
`Skills`, `User_Skills`, `Vacancy_Skills`, `Applications` кестелерімен жұмыс істейді.

## PyCharm арқылы іске қосу
1. ZIP архивін ашып, `job_recommender_site` бумасын PyCharm арқылы ашыңыз.
2. Өз курстық жұмысыңыздағы дайын `vacancies.db` файлын `docs` бумасына салыңыз
   (егер архивтегі база сіздің соңғы базаңыз болса, оны қалдыруға болады).
3. `main.py` файлын ашып, Run батырмасын басыңыз.
4. Браузерде `http://127.0.0.1:8000` сайты ашылады.
5. Тоқтату үшін PyCharm консоліндегі Stop батырмасын басыңыз.

## Сайт мүмкіндіктері
- Вакансияларды атауы, сипаттамасы және компаниясы бойынша іздеу.
- Қала, ең төменгі/жоғарғы жалақы және тәжірибе бойынша сүзу.
- Вакансиялар мен компаниялар санын көрсету.
- Вакансия талап еткен дағдыларды көрсету.
- Өтінім формасын толтырып, Applications кестесіне өтінім қосу.
- Жаңа өтінім берушіні Users кестесіне қосу (email бұрыннан бар болса, сол пайдаланушы қолданылады).

## Жоба құрылымы
- `main.py` — веб-сервер және деректер базасымен байланысатын API.
- `docs/index.html` — сайттың интерфейсі (HTML, CSS, JavaScript).
- `docs/vacancies.db` — курстық жұмыста бұрын құрылған SQLite базасы.

## Ескерту
Бұл — PyCharm ішінде іске қосылатын демонстрациялық веб-сервер. Басқа адамдарға интернет арқылы
ашық қолжетімді ету үшін серверді хостингке орналастыру, HTTPS, пайдаланушы аутентификациясы
және өндірістік қауіпсіздік баптаулары қажет.
